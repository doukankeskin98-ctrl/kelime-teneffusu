## İzlenen ekran haritası

- Yolculuk → Bölümler seçici → ana Solo → sonuç/inceleme. Yolculuk → Etkinlikler → Hikâyeler seçici → hikâye Solo.
- Etkinlikler → Günlük bulmaca → giriş/başlat/sonuç/sıralama. Etkinlikler → Oyun arşivi → Hızlı Tur, Gizli Tema, İpucu Avı, serbest tema/zorluk, tarihli/ek bölümler ve klasik oyun.
- Arena → hızlı grup/dereceli/özel oda → lobi → maç/sonuç/kurallar/sıralama. Arena → Arkadaşlar → davet/kod/ekip/haftalık lig/geçmiş. Arena → Meydan okuma → tema/kod/tahta/sonuç/paylaşım.
- Koleksiyon → dünya albümü/parçalar → ortak bölüm seçici, oyuncu profili/istatistikler, hikâye hatıraları, tarihli damgalar, başarılar, ayarlar.
- Üst ayarlar → ses/titreşim/kontrast/sol el/hareket/büyük tahta/renk/ölçüm, metin yardımı. Arşiv → oynanabilir alıştırma. Oyuncu oluşturma/giriş/kayıt/doğrulama/şifre yenileme.
