# Kelime Teneffüsü

Türkçe, mobil öncelikli kelime bulma oyunu.

Bu depo mevcut Hababam oyununun bağımsız sürümünü ve yeni tema kütüphanesini barındırır. Geliştirme için Lovable kredisi gerektirmez.

## Geliştirme

Kaynak aktarımı, standart React/Vite yapılandırması ve otomatik kontroller hazırlanıyor.

## Kaynak geçmişi

Başlangıç oyununun kaynak sürümü: `f1405b3be941f075039e1348510c5b08c0b0903e`.

Orijinal Hababam kelimeleri ve `hababam-kelime-v1` kayıt biçimi korunur.
